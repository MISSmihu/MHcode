# MHcode v0.3.20

## MCP 视觉桥接

- 文本模型收到图片时，可以调用用户配置的 MCP 视觉工具获取文字或结构化分析。
- MCP 设置支持选择视觉工具，并配置图片参数、提示词参数、Data URL/Base64、MIME 类型参数和文件名参数。
- 远程 Streamable HTTP/SSE MCP 的图片上传必须单独授权；未授权时不会发送图片内容。
- MCP 返回的图片内容和嵌入图片资源会保留为真实附件，不再只显示一个摘要字符串。
- 图片的视觉分析结果写入会话附件记录，切换会话、重启应用或上下文恢复后仍可使用。

## Windows 停止可靠性

- `exec.CommandContext` 的取消回调现在通过 Windows Job Object 终止整个命令树，而不是只结束根进程。
- 增加进程尚未完成 Job Object 绑定时的取消竞态保护。
- 增加应用级和底层 Windows 子进程树回归测试。
